# Machine-readable downloads

- [Catalog JSONL](downloads/catalog.jsonl): one complete entity per line; recommended for AI and code.
- [Catalog CSV](downloads/catalog.csv): one entity per row; nested lists and objects are JSON strings inside CSV cells.
- [JSON Schema](downloads/catalog.schema.json): Draft 2020-12 structural contract.
- [SDG crosswalk CSV](downloads/sdg-indicators.csv): selected evidence-linked many-to-many mappings.
- [Canonical curated YAML](https://github.com/boris-belyavskiy/open-global-data-atlas/tree/main/catalog): edit these records, then manually render the exports.

All downloads are metadata. No original respondent files or provider statistical observations are redistributed. See the [schema reference](schema-reference.md) and [methodology](methodology.md).
