# Global SDG Indicators Database

Official dissemination of indicator series supplied through the SDG custodian process. SDGs are a separate policy crosswalk.

**Dataset card · OPEN · Free data route documented**

[Open original source](https://unstats.un.org/sdgs/indicators/database/)

| Field | Value |
| --- | --- |
| Stable ID | sdg-global |
| Organization | [United Nations Secretariat](un.md) |
| Original producer | National statistical systems and SDG custodian agencies; see each indicator metadata file. |
| Collector | National statistical offices, administrative systems or survey teams; varies by source. |
| Publisher | United Nations Statistics Division |
| Data level | aggregate |
| Observation units | country, region |
| Coverage | Global / multi-region |
| Confirmed country examples | Not enumerated |
| Time coverage | Varies by series, country and release; consult the original source. |
| Release | Select the current series or release at the source |
