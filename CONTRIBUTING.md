# Contributing

1. Choose the correct entity level. Prefer a single study ID with catalog references to copies of the same study.
2. Write all names, descriptions, comments and documentation in English. Keep the official source identity recognizable.
3. Verify an official landing page and the access policy. Record evidence URLs, the date and exactly what was checked. Do not infer free data from a public metadata page.
4. Separate producer, collector and publisher. Explain any UN partner relationship instead of inferring it from citations.
5. Tag relevant A/B topics; put SDGs in the separate crosswalk. Record data levels and observation units independently.
6. Use only confirmed country codes and say whether coverage is partial. Explain fieldwork, waves and weights for survey records.
7. Edit canonical YAML, manually run the rendering/build/check commands in README, review the diff, and commit generated artifacts together. Remove stale generated record pages when deleting a record.

Do not add importers, workflows, automated publishing, external tracking or schedules without a separate project decision. Do not commit credentials, provider microdata or downloaded statistical observations. Propose corrections with the exact record ID and official evidence.
